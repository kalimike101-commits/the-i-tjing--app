# The I-Tjing

A native Android I Ching application built in Kotlin.

The project aims to provide an authentic three-coin I Ching consultation experience, combining traditional I Ching structure with clear, contemporary interpretation.

## Current status

Een native Android I Ching-applicatie die is gebouwd in Kotlin.

Het project heeft tot doel een authentieke I Ching-consultatie-ervaring met drie munten te bieden, waarbij de traditionele I Ching-structuur wordt gecombineerd met een duidelijke, eigentijdse interpretatie.
🚧 Work in progress — early development.

The casting engine uses the traditional three-coin method, including changing lines and transformed hexagrams.

## Development

Built with Kotlin and Jetpack Compose.
